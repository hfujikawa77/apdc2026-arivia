# apdc2026-arivia

Slides for "Arivia: Water-Surface Drone Shows with ArduPilot" (ArduPilot DevConf 2026, Ottawa).

- English: `en/index.html`
- Japanese: `ja/index.html`
- English, lighter (less text per slide, videos on their own slides): `en-2/index.html`
  - Speaker view (en-2): press `S` to open it (current/next slide, English script, key points, time budget, timer). The script is embedded from `speaker-notes2.md` in claw-io-hub.

Built with reveal.js (CDN). Serve over HTTP (e.g. `python3 -m http.server`) so the embedded YouTube videos play.
- Themes: pick one on the top page, or add `?theme=night` (default) / `dracula` / `moon` / `sky` etc. to a slide URL; the choice is remembered in the browser.
